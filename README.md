# Bolaga ism

Статический каталог узбекских имён. Главная страница — `index.html`, логика — `app.js`, оформление — `style.css`.

## Данные и публикация

`convert_excel_to_json.py` читает `uz_names.xlsx` и создаёт `names.json` и `names_data.js`. Требуются Python, pandas и openpyxl. GitHub Actions выполняет преобразование и публикует сайт через GitHub Pages при push в `main`.

Сайт загружает `names.json`, а при его отсутствии использует `names_data.js`. Для локального просмотра используйте HTTP-сервер, например `python -m http.server 8000`.

## Ссылки и избранное

- `?q=Abbos` — поиск.
- `?jins=m&harf=Sh` — каталог по полу и букве.
- `?ism=m%3Aabbos` — конкретное имя. Ключ состоит из пола и нормализованного написания; ссылка формируется кнопкой Telegram.

Избранное хранится в localStorage под ключом `ismlar_favorites_v3` семь дней. Ключ имени не зависит от порядка строк Excel. Старые записи v2 переносятся по ID после загрузки полной базы. Для переноса нужна прежняя нумерация данных; переименование самого имени требует отдельной миграции.

Подборка из десяти имён задаётся редакционно. Сайт не показывает искусственные счётчики просмотров.

## Проверки

Нужны Node.js, пакет `playwright` и установленный Microsoft Edge. Запустите из корня проекта:

```sh
node --check app.js
node test-site.cjs
```

Тесты проверяют поиск по URL, открытие дальних карточек, специальные буквы, прямые ссылки, удаление избранного, перенос v2 и истечение срока. Внешние запросы в тестах блокируются; файлы сайта подаются через перехват запросов. Тест не проверяет публикацию и рекламу.
